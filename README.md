# Blockoo-Constructor

«Blockoo» — это легковесный, быстрый и оптимизированный под мобильные устройства конструктор визуального программирования.

### 🛠 Стек технологий
Проект построен на базе чистых веб-технологий без тяжелых фреймворков, что обеспечивает максимальную скорость работы:
* **HTML5 / CSS3** — адаптивный интерфейс и верстка, заточенная под тач-скрины.
* **JavaScript (ES6+)** — движок конструктора, логика визуальных нод и обработка данных.

### 🌟 Главные фичи
* **Интуитивные ноды.** Логика блоков понятна с первого взгляда, порог входа минимальный.
* **Гибкие возможности.** Несмотря на простоту, на базе доступных нод можно собрать полноценную рабочую игру.
* **Конфиденциальность.** Логика ваших игр и проектов обрабатывается локально и полностью защищена от чужих глаз.

### ⚠️ Текущие ограничения
* **Локальное хранение.** Проекты остаются внутри редактора, функция экспорта и шаринга кода пока отсутствует.
* **Границы конструктора.** На Blockoo можно создать множество игровых механик, но, как и у любого визуального конструктора, у него есть свой лимит возможностей.
